# Codex Aureus · 黄金古卷

> **中世纪泥金手抄本艺术交互网页**  
> An illuminated medieval manuscript web experience. Built with pure HTML/CSS/JS, featuring parchment textures, gothic arches, interactive wax seal, and synthesized Gregorian chant.

---

## ✨ 项目特色 / Highlights

- **📜 逼真古卷质感**：纯 CSS 拟真羊皮纸泛黄暗角与金箔光泽，结合精选古典字体（*Cinzel Decorative* / *EB Garamond* / *MedievalSharp*）。
- **⚜️ 泥金首字（Illuminated Drop Cap）**：重现中世纪缮写室经典技艺，青金石蓝底衬托金箔大写字母与茛苕卷草纹样。
- **🏰 哥特式尖拱布局**：双圆心哥特尖拱画廊卡片，建筑感典藏排版。
- **🕯️ 拟真交互印章与烛光**：不规则边缘与微立体火漆封印互动反馈，支持开启烛光阅读模式。
- **🎵 Web Audio 实时圣咏**：无外部大音频文件依赖，纯代码通过多振荡器、共振峰滤波与教堂卷积混响实时合成多利亚调式多声部圣咏。
- **⚡ 零依赖·完全离线**：本地打包单文件与离线字体资源，无需 Node.js、后端服务或构建打包步骤，双击即可直接运行。

---

## 🚀 快速开始 / Quick Start

本仓库为纯静态项目，无需安装任何依赖：

1. 克隆或下载本仓库到本地：

   ```bash
   git clone https://github.com/你的用户名/codex-aureus.git
   ```

2. 双击打开 `index.html`，即可在任意现代浏览器（Chrome、Edge、Safari、Firefox）中全功能浏览体验。
